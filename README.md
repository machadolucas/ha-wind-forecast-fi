# Wind Forecast Finland

A Home Assistant custom integration that provides Finland wind-generation
forecasts (Fingrid + FMI, with a combined/best-source sensor) as cached,
never-empty entities in a consistent MW schema.

> **Status: under construction.** Scaffold and pure forecast-parsing modules
> are in place; the Home-Assistant-facing pieces (coordinators, config flow,
> entities) are landing in later commits. Full README (install, configuration,
> entity reference, dashboard card) lands with the v1.0.0 release.
